# 🧠 MNIST.AI: Digit Recognizer

A full-stack machine learning application that uses a **Convolutional Neural Network (CNN)** to identify handwritten digits in real-time.

## 🚀 Features

- **Interactive Canvas:** Smooth drawing experience using React.
- **FastAPI Backend:** High-performance Python API for model inference.
- **Deep Learning:** Trained on the MNIST dataset using TensorFlow/Keras.
- **Modern UI:** Built with Vite, React, and Tailwind CSS.

## 🛠️ Tech Stack

- **Frontend:** React, Vite, Tailwind CSS, Lucide Icons
- **Backend:** Python, FastAPI, Uvicorn
- **ML:** TensorFlow, NumPy, Pillow (PIL)

## 📦 Installation

### Backend

1. Navigate to the `backend` folder.
2. Create a virtual environment: `python -m venv venv`.
3. Install dependencies: `pip install -r requirements.txt`.
4. Start the server: `uvicorn api.index:app --reload`.

### Frontend

1. Navigate to the `frontend` folder.
2. Install dependencies: `npm install`.
3. Start the dev server: `npm run dev`.
